## 📖 О проекте

SchoolSpace - это веб-приложение для учащихся, где можно задавать вопросы по учебным предметам, получать ответы от сообщества и помогать другим. Платформа включает систему жалоб, модерации и социальные функции.

### 🌟 Основные возможности

- **❓ Задавание вопросов** с поддержкой изображений
- **💬 Ответы на вопросы** с системой комментариев
- **👤 Профили пользователей** с уровнями и достижениями
- **🛡️ Система модерации** и жалоб
- **👑 Админ-панель** для управления контентом
- **📚 Фильтрация по предметам и классам**
